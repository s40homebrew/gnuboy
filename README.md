# Gnuboy for Nokia Series 40

A native Game Boy / Game Boy Color emulator using the shared S40 homebrew SDK.
The Nokia 6303 classic port has a ROM picker, keypad controls, aspect-preserving
scaling, battery saves, a save-state slot and optional native sound output.

See [installation, controls and builds](s40/README.md). The original desktop
backends and [upstream documentation](README) remain available.

Gnuboy and this port are GPL-2.0-or-later; see [COPYING](COPYING). The S40 SDK
retains its own MIT and linked-library notices in the application package.
